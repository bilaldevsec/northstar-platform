# Incident Response & Severity Levels
| Severity | Definition | Response SLA | Update Cadence |
|---|---|---|---|
| SEV1 | Customer-facing outage or data breach | 15 min (24/7) | Every 30 min |
| SEV2 | Major degradation (e.g., 20% error rate) | 30 min (24/7) | Hourly |
| SEV3 | Minor impact / internal tool down | Next business day | Daily |
| SEV4 | No impact / cosmetic | Backlog | None |
